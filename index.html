iPhone Install Guide
Host MY Tracker for free on GitHub Pages, then install it on your iPhone.
✅ Your data never touches GitHub. The file is just code — all your transactions stay on your device only.
Part A — Host on GitHub (one-time setup)
1
Go to github.com on your computer and tap Sign Up. Use your personal email. Verify your email address.
2
Click the green "New" button → Repository name: my-tracker → tick "Add a README" → click "Create repository"
3
Click "Add file" → "Upload files". Drag your MoneyTracker.html file onto the page. Important: before uploading, rename the file to index.html. Click "Commit changes".
4
Go to Settings tab (top of repo) → left sidebar click "Pages" → Source: "Deploy from a branch" → Branch: main → Folder: / (root) → click Save. Wait 3 minutes.
5
Your app is live at:
https://YOUR-USERNAME.github.io/my-tracker
Part B — Install on iPhone 17 Pro
1
Open your GitHub Pages URL in Safari (not Chrome)
2
Tap the Share ⬆ button at the bottom of Safari
3
Scroll down and tap "Add to Home Screen"
4
Tap "Add" in the top-right corner. Done — MY Tracker appears on your Home Screen like a native app.
🔒 Security Notes
• Your financial data never leaves your phone — GitHub only hosts the app code
• The GitHub repo is Public — this is safe, it contains zero personal data
• Never paste your Notion token into the HTML file before uploading
• Export a JSON backup monthly → save to iCloud Drive
• If you ever change the file, re-upload index.html to GitHub to update it
